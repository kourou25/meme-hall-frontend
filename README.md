# 尽欢 · 前端

> 发出 meme 千万张，欲得摸鱼佬友尽欢颜。

「尽欢」梗图交流站的前端代码。站点基于 Linux.DO 账号登录，支持图廊浏览、表情回应、一句回应、收藏、评论、解密谜题、群聊等。

- 已构建的静态文件，不需要再次构建：原生 JS 入口 `index.html` 与 React 账号页面入口 `app.html`，React 脚本和样式在 `assets/`
- 平台表情在 `stickers/`，第三方库自托管在 `vendor/`（各自附带许可证）
- 服务端（Cloudflare Workers + D1 + R2）不在本仓库，前端单独无法完整运行

本仓库由私有主仓库的 Vite 客户端构建产物自动同步，仅包含公开前端资源。后端代码、数据库和本地配置不在同步范围内。请不要直接在这里提交修改。

## 2026-10-27 音乐播放器更新

对应生产版本 73855e01-d74d-4a11-a6d3-f6f518d651de，客户端 8f410db6。蓝紫浅色与黑金红暗色均使用纯色背景，手机音乐库采用紧凑歌单入口；没有大幅介绍横幅。样式加载就绪后显示组件，避免慢网络下的图标和布局变形。

播放器支持拖动、缩成二次元图标、关闭后暂停并保留歌曲与进度。点击歌名进入唱片详情，点击封面切换多行歌词；悬浮歌词支持拖动、横竖排、字体、颜色和字号；逐字时间戳按歌词行解析，保留后续副歌，避免重复整句。

站长推荐与欢友歌单提供署名推荐和撤回。公共推荐需要服务端 API，私人歌单仍存于当前设备。搜索支持分页、去重及同曲失败恢复；上游音源可用性不作保证。24bit 外部入口已移除，未接入未经验证的自动搜索接口。

公共推荐接口：GET /api/music/playlists/owner 或 friends；POST 对应地址提交 track 字段（本站签发的歌曲 token 字符串）与可选 alternates（token 数组）；DELETE /api/music/playlists/:list/:key 撤回本人推荐。需登录，站长歌单写入另需站长权限，署名由服务端账号决定。站点自有 API 实现与数据库不在本仓库。

本次修改的第三方音乐服务使用 AGPL-3.0，按其许可证提供[对应源码与构建说明](third-party/music-service/README.md)和[源码下载](third-party/music-service/music-pagination-source-20261027.zip)。该目录不适用本站代码的 MIT 授权；各上游许可证保留。源码不含站点 Worker、凭据或用户数据。
